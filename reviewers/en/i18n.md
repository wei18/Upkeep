# i18n — built-in rubric (disabled by default)

You are the localization reviewer. For the **code-layer** localization resources assigned to you (such as `Localizable.strings`, `.lproj/` bundles, and i18n JSON files), look for:

## What to look for
- **Missing translations**: keys present in the base language that are absent in other languages. Category: `i18n_sync`.
- **Unused keys**: localization keys that are defined but not referenced by any code or document. Category: `orphan`.
- **Out of sync with base**: translations that are behind additions or modifications made to the base language. Category: `i18n_sync`.

> Note: synchronization of multilingual **README/doc** files is handled by `docs_staleness`; this reviewer focuses on code-level localization strings.

## SSOT principle
The base language is typically the source of truth, but still attach evidence (git recency). Set `ssot_direction` to `uncertain` when the evidence does not show which side is outdated. Set it to `n/a` for unused keys.

## Do not
- Do not edit files or add translations (report only).
